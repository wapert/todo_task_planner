# 1.0.5 — App Store「What's New」

Covers what changed since **1.0.4** (released). Paste into App Store Connect →
Version 1.0.5 → What's New in This Version, into both localizations.

---

## 繁體中文

```
新增「連續期間」任務
• 可建立橫跨多天的任務：選擇起訖日期，中間每一天都會自動納入
• 適合旅行、課程、專案這類持續一段時間的事情
• 清單中只會顯示一筆，標示完整期間與今天是第幾天
• 在任何一天打勾，整個任務就算完成

更順手的操作方式
• 點一下任務即可查看、編輯或刪除，不再需要額外的按鈕
• 向右滑動標記完成，向左滑動刪除
• 備註過長時會自動收合，可點「顯示更多」展開

畫面調整
• 任務欄位加寬，可顯示更多文字
• 各頁面的任務寬度一致
```

## English

```
New: Multi-day tasks
• Create a task that runs across a range of days — pick a start and end date
  and every day between is included
• Suited to trips, courses and projects that last a while
• It appears once in the list, showing the full range and which day of it
  today is
• Tick it off on any day and the whole task is done

Quicker to use
• Tap a task to view, edit or delete it — no more separate buttons
• Swipe right to complete, swipe left to delete
• Long notes are collapsed, with "Show more" to expand them

Layout
• Wider task rows, so more text fits
• Consistent task width across every page
```
