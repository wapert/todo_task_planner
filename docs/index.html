常見問題 / FAQ

  • 如何同步到其他裝置？ 用同一個帳號登入即可自動同步。
  • 可以用哪些方式登入？ Apple 帳號、Google 帳號，或電子郵件註冊。
  • 如何把任務加到行事曆？ 「設定 → 行事曆同步」，需要授權行事曆存取；不授權也不影響其他功能。
  • 如何啟用 Face ID 登入？ 「設定 → 帳號 → 使用生物辨識登入」。
  • 如何刪除帳號？ 「設定 → 帳號 → 刪除帳號」，將永久移除帳號與雲端資料。
  • How do I sync? Sign in with the same account on each device.
  • How do I delete my account? 設定 (Settings) → 帳號 (Account) → 刪除帳號 (Delete Account).
